Create a futuristic 3D web application called “STARK WORLD”.

IMPORTANT:
- This is a real interactive web app prototype, not just a static landing page.
- Use a premium, modern, cinematic interface.
- Avoid old-fashioned sci-fi HUD designs, pixel-style graphics, excessive neon outlines, or cluttered panels.
- The design should feel like a high-end technology product from the near future.
- Use smooth glassmorphism, subtle blue/cyan lighting, soft gradients, depth, shadows, and clean typography.
- The interface must look excellent on both desktop and mobile.
- AI functionality is NOT implemented yet. Show “AI OFFLINE” where appropriate.
- Prioritize smoothness, simplicity, and real interaction.

APP CONCEPT:
STARK WORLD is a personal futuristic control environment.
The user can explore a 3D digital space, inspect objects, monitor system status, scan the environment, and execute commands.

MAIN SCREEN:
Create a large immersive 3D space in the center of the screen.

At the center:
- A glowing futuristic energy core called “ARC CORE”
- The core should look like a sophisticated 3D energy reactor
- Use a transparent outer shell
- Several thin rotating rings around the core
- Soft blue/cyan illumination
- Subtle particles floating around it
- The core should continuously animate

Around the core:
- 4 smaller energy nodes
- NORTH NODE
- EAST NODE
- WEST NODE
- SOUTH NODE
- Connect the nodes to the ARC CORE with subtle glowing lines
- Each node should be clickable
- Clicking a node opens its information panel

3D INTERACTION:
- Allow mouse drag to rotate the camera around the environment
- Allow mouse wheel to zoom
- Support touch drag on mobile
- Support pinch-to-zoom on mobile
- Clicking/tapping a 3D object selects it
- Selected objects should have a subtle visual highlight
- Add smooth camera transitions when selecting objects

PERFORMANCE:
Keep the 3D scene lightweight and smooth.

Make the interface feel responsive.
